# Helm

Helm is a desktop app for building things with AI: chat with Claude or other models, let them read and change your project files, check websites in a built-in browser, and undo anything with one click.

This repository only holds the **installers and update files**. There is no source code here.

## Download

Go to **[Releases](https://github.com/matixacik-cell/helm-releases/releases/latest)** and download:

- **Windows:** `Helm-Setup-<version>.exe`
- **Mac (Apple Silicon):** `Helm-<version>-arm64.dmg`

## First open

- **Windows:** if you see "Windows protected your PC", click **More info**, then **Run anyway**.
- **Mac:** right-click Helm in Applications, choose **Open**, then **Open** again (only the first time).

On first launch Helm asks how it should think: sign in with your own **Claude Code**, or paste your own **API key** (Anthropic, OpenAI, DeepSeek, OpenRouter, Google...). Your keys stay on your computer.

## Updates

Helm updates itself. When a new version is ready you'll see **"Restart to update"** at the bottom of the window.
